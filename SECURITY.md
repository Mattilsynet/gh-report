# Security Policy

If you find a vulnerability anywhere in gh-report, such as the source or scripts, then please let the Mattilsynet project admins know ASAP and we will fix it as a critical priority.

[Open a private security advisory](https://github.com/Mattilsynet/gh-report/security/advisories/new) to report it confidentially to the project admins. Do not report vulnerabilities in public issues or pull requests.

We welcome analysis and proof of concepts generated by AI, but for the advisory to be accepted it must have had human oversight and checking.

Failure to follow this policy may result in the advisory being closed and/or no credits given to the reporter.
